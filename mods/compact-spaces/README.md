# Compact Spaces

Owned clone of the shipped Spaces mod. The herdr-workspace layout fixes it at 44 logical pixels and disables dragging the divider above Agents; Agents retains its flexible height.

The trigger reflects Herdr's actual selected space. Open it to select a space or create one on a ready machine. Arrow keys move a temporary highlight, Enter activates the exact live ID, and Escape cancels. Right-click retains the native space menu; drag between popup space rows to reorder within a machine.

Machine-qualified IDs distinguish equal names. Removed spaces and unavailable machines cannot fall back to another index or create locally. Collapsed sidebars retain a labelled avatar trigger and popup create actions. Space colors, attention and worktree grouping use the shipped model.

No independent space selection is saved. The layout installation journal in the retained execution workspace records only the owned mod reference, height and minimum. Agent sessions, Plan and Files/Changes are unchanged. Native popup mouse/keyboard and narrow/zoom acceptance still require a user-visible check when GUI automation is unavailable.
